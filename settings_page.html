Smart Suppression
Reduce sensitivity during normal activity
When NetWatch detects you're streaming video, doing a large download, or uploading files, it automatically reduces sensitivity so these don't trigger false alerts. Suspicious connection patterns (SYN floods, port scans) are always detected regardless.
